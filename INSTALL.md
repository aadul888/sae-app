# Panduan Instalasi SAE App

## Persyaratan

- **PHP** 8.1+ (8.3 direkomendasikan)
- **MySQL/MariaDB** 5.7+ (8.0+ direkomendasikan)
- **Web Server** Apache (dengan mod_rewrite aktif)
- **Git** untuk clone repository

## Langkah-Langkah Instalasi

### 1. Clone Repository

```bash
git clone https://github.com/aadul888/sae-app.git
cd sae-app
```

### 2. Akses Installer

Buka browser dan navigasi ke:

```
http://your-domain.com/installer
```

Contoh untuk Laragon lokal:

```
http://sae-app.test/installer
```

### 3. Isi Formulir Instalasi

Installer akan menampilkan form untuk mengatur koneksi database:

- **Nama Database**: Masukkan nama database (akan dibuat otomatis jika belum ada)
- **Username Database**: Username akun database
- **Password Database**: Password akun (kosongkan jika tidak ada password)

Klik **"Lanjutkan Instalasi"** untuk memulai proses.

### 4. Proses Instalasi Otomatis

Installer akan secara otomatis:

1. Mendeteksi host dan port database
2. Membuat database jika belum ada
3. Import schema dan data default dari `database/db_sae.sql`
4. Membuat file `.env` dengan credentials
5. Set cookie auto-login untuk admin
6. Redirect ke dashboard

### 5. Akses Aplikasi

Setelah instalasi selesai, Anda akan otomatis diarahkan ke dashboard admin.

**Akun Default:**

- **Username**: `admin@sae.id`
- **Password**: `Admin543!`

## Konfigurasi Ulang

Jika Anda perlu mengkonfigurasi database lagi (misalnya mengganti server):

1. **Hapus file `.env`** dari root folder
2. **Akses `/installer`** lagi
3. Ikuti langkah-langkah instalasi seperti di atas

## Keamanan

### File `.env`

- File `.env` **TIDAK** akan di-commit ke Git (sudah di `.gitignore`)
- File ini **hanya ada di server/lokal** Anda
- Berisi credentials sensitif — jaga keamanannya

### Permissions

Pastikan folder root memiliki write permission untuk PHP:

```bash
# Linux/Mac
chmod 755 /path/to/sae-app
chmod 755 /path/to/sae-app/library
chmod 755 /path/to/sae-app/content

# Windows: Beri read/write permission untuk user IIS/Apache
```

## Update Dari Repository

Saat ada update dari repository, cukup lakukan:

```bash
git pull origin main
```

**Database Anda akan aman** — update tidak akan menimpa `.env` atau data di folder `content/`.

## Troubleshooting

### Error: "Koneksi database gagal"

- Pastikan MySQL/MariaDB server berjalan
- Verifikasi username dan password database
- Cek apakah database user memiliki CREATE DATABASE privilege

### Error: ".env file tidak dapat ditulis"

- Pastikan folder root memiliki write permission untuk web server
- Cek file/folder permissions
- Ubah ownership jika perlu: `chown www-data:www-data /path/to/sae-app`

### HTTP 500 saat instalasi

- Cek error log web server (Apache: `error.log`)
- Pastikan PHP extensions yang diperlukan aktif: `mysqli`, `json`
- Verifikasi database credentials

### Installer tidak muncul

- Pastikan `.env` belum ada (atau hapus terlebih dahulu)
- Verifikasi `.htaccess` aktif (di Apache)
- Cek file permissions (`installer.php` harus readable, route publiknya `/installer`)

## Struktur Folder

```
sae-app/
├── .env                 # Generated by installer (user-specific, not in git)
├── .env.example         # Template .env
├── installer.php        # First-time setup (standalone)
├── index.php            # Main entry point
├── database/
│   └── db_sae.sql       # Database schema & initial data
├── library/
│   ├── config.php       # Configuration loader (.env reader)
│   ├── function.php     # Global functions
│   └── ...
├── module/              # Modul aplikasi
├── admin/               # Admin dashboard
├── content/             # User uploads & cache (not in git)
└── ...
```
